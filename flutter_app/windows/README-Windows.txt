StreetPass for Windows

1. On a new Windows PC install the official Microsoft Visual C++ x64 Redistributable:
   https://aka.ms/vs/17/release/vc_redist.x64.exe
2. Extract this whole folder.
3. Run streetpass.exe.
4. Turn on Bluetooth and enable discovery in the app.

Do not copy only the EXE: the data folder and DLL files beside it are required.
